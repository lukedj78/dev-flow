03 how to use them

You don't need to remember which skill you need: let the orchestrator guide you, or call one by name. Some trigger on their own from the topic you mention.

Open the project and say what you want: dev-flow reads meta.json#phase and suggests (or invokes) the right skill.

04 installation

How to install them

They're markdown-portable: they end up in ~/.claude/skills/<name>/ (or your runtime's equivalent). Five runtimes: Claude Code · Codex · Copilot · Gemini · Cursor.

install.sh — recommended
$git clone git@github.com:lukedj78/dev-flow.git
$cd dev-flow
$./install.sh # Claude Code (default)
$./install.sh --platform codex # or copilot · gemini · cursor

Copies all the skills into the runtime's path plus the right bootstrap file (AGENTS.md / GEMINI.md / .cursorrules), with .bak backups of anything existing. Uninstall and restore with ./uninstall.sh.

B Plugin

Claude Code, from the repo cloned locally.

›/plugin add …/dev-flow/dev-flow
C gh skill

Via GitHub CLI — all of it or a subset.

$gh skill install lukedj78/dev-flow
D Drag & drop

Drag the .skill packages into the window.

dist/*.skill → Claude Code
