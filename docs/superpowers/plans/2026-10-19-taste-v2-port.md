# taste-skill v2 port — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use `- [ ]`.

**Goal:** fix what taste-skill v2 showed we get wrong, take the ideas we lack, decline the rest — spec F1–F5, T1–T7.
**Architecture:** prose rules in `design-md-to-app` / `wireframe-canvas` / `transitions`, each rule that can be counted
counted by a script (`check.py`, `wireframes.py argument`, `render_probe.mjs`), every script with a unittest suite
discovered by `run_skill_tests.py`.
**Tech stack:** Python 3.9+ stdlib, Node ≥ 22 (built-in WebSocket) + Chrome DevTools Protocol, no npm dependency.
**Spec:** `docs/superpowers/specs/2026-10-19-taste-v2-port-design.md`

## Global constraints
- Code and identifiers in English; user-facing strings in templates through `useTranslations` (en + it).
- Type through the redefined `--text-*` slots (`text-sm`, `text-4xl`…), never `text-[Npx]` outside the showcase specimen.
- Every anti-slop rule bows to the source (Step 4.5c).
- Credit taste-skill (MIT) where an idea lands; copy no text.
- Commit trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; never commit `docs/audit-prompt.md`.

## Review focus
1. A page whose copy lives only in `messages/*.json` — `invented-proof` must read those files, and must not fire on
   a key name or on sample rows in an app screen.
2. A project with no public screen (dashboard only) — `approve` must not demand a page argument.
3. Probe on a machine without Chrome or with Node < 22 — a clear message and a distinct exit code, never a stack trace;
   the suite skips (counted), never passes silently.
4. Probe against a page that is slow to settle or has a hidden mobile nav — `display:none` / `aria-hidden` /
   off-canvas elements are not "invisible text" and not overflow culprits.
5. Italian strings in the templates — every visible string comes from messages; `© {year}` formatted, not concatenated.
