# Post-bootstrap checklist

After `monorepo-bootstrap` finishes, verify each item before bumping `meta.json#phase` to `scaffolded`. The `scripts/verify.ts` automates most of this.

## File existence (root)

- [ ] `pnpm-workspace.yaml` exists and lists `apps/*` + `packages/*`.
- [ ] `turbo.json` exists and has the canonical pipeline (build/dev/lint/test/typecheck).
- [ ] Root `package.json` with the name `@<slug>/root`, scripts proxy to turbo.
- [ ] `tsconfig.base.json` with `paths` aliases for `@<slug>/shared/*`, `@<slug>/design/*`, `@<slug>/api/*`.
- [ ] `.gitignore` covers `node_modules/`, `.next/`, `.expo/`, `dist/`, etc.

## File existence (apps/web)

- [ ] `apps/web/package.json` exists with name `@<slug>/web`.
- [ ] `apps/web/package.json` dependencies include `@<slug>/shared`, `@<slug>/design`, `@<slug>/api` as `workspace:*`.
- [ ] `apps/web/tailwind.config.js` exists and imports `require('@<slug>/design/tailwind').default` as a preset.
- [ ] `apps/web/tsconfig.json` extends `../../tsconfig.base.json`.
- [ ] `apps/web/app/_layout.tsx` (or `apps/web/app/page.tsx`) exists.
- [ ] `apps/web/next.config.ts` exists (auto-generated by create-next-app).

## File existence (apps/mobile)

- [ ] `apps/mobile/package.json` exists with name `@<slug>/mobile`.
- [ ] `apps/mobile/package.json` dependencies include `@<slug>/shared`, `@<slug>/design`, `@<slug>/api` as `workspace:*`.
- [ ] `apps/mobile/tailwind.config.js` exists and imports `require('@<slug>/design/nativewind').default` as a preset (after `require('nativewind/preset')`).
- [ ] `apps/mobile/metro.config.js` exists with `watchFolders = [workspaceRoot]` + `disableHierarchicalLookup: true`.
- [ ] `apps/mobile/tsconfig.json` extends `../../tsconfig.base.json`.
- [ ] `apps/mobile/app/_layout.tsx` and `apps/mobile/app/index.tsx` exist.
- [ ] `apps/mobile/nativewind-env.d.ts` exists.

## File existence (packages/design)

- [ ] `packages/design/package.json` with name `@<slug>/design`, `main: ./src/tokens.ts`, exports map.
- [ ] `packages/design/src/tokens.ts` with token values from `.workflow/DESIGN.md` (or defaults if missing).
- [ ] `packages/design/src/tailwind-preset.ts` exports a Tailwind config preset.
- [ ] `packages/design/src/nativewind-preset.ts` exports a NativeWind config preset.
- [ ] `packages/design/tsconfig.json` extends base.

## File existence (packages/shared)

- [ ] `packages/shared/package.json` with name `@<slug>/shared`, main `./src/index.ts`.
- [ ] `packages/shared/src/index.ts` (barrel export, can be empty initially).
- [ ] `packages/shared/src/types/`, `validators/`, `utils/` directories.
- [ ] `packages/shared/tsconfig.json` extends base.

## File existence (packages/api)

- [ ] `packages/api/package.json` with name `@<slug>/api`, main `./src/index.ts`.
- [ ] `packages/api/src/client.ts` (placeholder for backend client).
- [ ] `packages/api/tsconfig.json` extends base.

## Install + verify

- [ ] `pnpm install` from root succeeds.
- [ ] `pnpm tsc --noEmit` from each `apps/*` and `packages/*` passes.
- [ ] `pnpm turbo dev --dry-run` lists all 5 workspaces (root + 2 apps + 3 packages).

## meta.json state

- [ ] `meta.json#stack.framework == "monorepo"`.
- [ ] `meta.json#stack.monorepo.web.framework`, `.ui` populated.
- [ ] `meta.json#stack.monorepo.mobile.framework="expo-rn"`, `.ui="nativewind"`.
- [ ] `meta.json#stack_config.monorepo_tool="turborepo"`.
- [ ] `meta.json#stack_config.workspace_pm="pnpm"`.
- [ ] `meta.json#stack_config.shared_packages` lists all 3 (`@<slug>/shared`, `design`, `api`).
- [ ] `meta.json#phase == "scaffolded"`.
- [ ] `meta.json#history` has the bootstrap entry.

If any item fails: do NOT bump the phase. Report the failure and stop.
